What comes with you

Moved for you

  • Every Space, as a Zen Space
  • Folders, including folders inside folders
  • Pinned tabs, in the same order
  • Favorites, as Zen Essentials

Not moved by this

  • Passwords
  • History
  • Extensions
  • Tabs you hadn't pinned

Save your passwords somewhere safe before December 22. The FAQ below explains how.

Five steps

Do this on the Mac where you use Arc. Keep Arc installed until you're done.

You seem to be on a phone or another computer. Open this page on your Mac to follow along.

  1. Get Zen, open it once, then quit it

    Download Zen from zen-browser.app and open it so it can set itself up. Then quit it completely: with Zen in front, press ⌘ Q.

    Already using Zen? Just quit it. Closing the window isn't enough; Zen has to be fully quit for the move to work.

  2. Open Terminal

    Terminal is an app that's already on every Mac. Press ⌘ Space, type Terminal, and press Return.

    You'll seeA plain window with a line of text ending in %. That's it waiting for you.

  3. Copy this line, paste it into Terminal, press Return

    cd ~ && curl -fsSLO https://raw.githubusercontent.com/Glebelov96/arc-to-zen-guide/main/arc2zen.py && python3 arc2zen.py

    To paste, click inside Terminal and press ⌘ V. This downloads a small helper and starts it. It reads your Arc sidebar and doesn't change Arc.

    If your Mac asks to install “command line developer tools”Click Install, wait for it to finish (a few minutes), then paste the line again.

  4. Answer a few questions

    The helper shows what it found in Arc and asks before changing anything. Pressing Return picks the suggested answer, which is right for most people.

    • Which profile should I use? Only asked if your Mac has more than one Zen setup. It shows the Spaces in each one; pick the one you recognise.
    • Also add your Arc Favorites as Zen Essentials? Your Favorites become the icons at the top of Zen's sidebar.
    • Go ahead? Saves a backup of Zen first, then moves everything.
    You'll see“Done. Open Zen — your Arc Spaces are in the sidebar.”

  5. Open Zen

    Your Spaces are in the sidebar with their folders. Switch between them with the icons at the bottom of the sidebar, or by swiping with two fingers. Each tab loads the first time you click it.

Changed your mind?

Quit Zen with ⌘ Q, open Terminal, and paste this. It puts Zen back exactly as it was before the move.

cd ~ && python3 arc2zen.py --undo

Questions

Is this safe?

It only reads Arc's sidebar file and only changes Zen's list of tabs, after saving a copy so you can undo. It runs entirely on your Mac and sends nothing over the internet. The code is public on GitHub if you or a techy friend want to read it.

It said “Zen is open”

Zen is still running in the background. Click Zen, press ⌘ Q, wait a few seconds, and paste the line again.

It finished, but Zen looks the same

Your Mac has more than one Zen setup and a different one was picked. Quit Zen, open it, create a Space with an unusual name, quit Zen again, and run the line once more. Pick the profile that lists the Space you just made.

What about my passwords?

The helper doesn't move passwords. Before December 22, save them somewhere you trust, such as a password manager or Apple Passwords. If you export them to a file along the way, delete the file afterwards, because anyone can read it.

Should I just use Dia instead?

The Browser Company recommends its new browser, Dia, which imports Arc directly, including passwords and history. If you'd like to stay with that team, that's the easiest path. This page is for people who'd rather move to Zen.

I'm on Windows

This helper is for Macs only for now. On Windows, use Arc's own option to export a list of your tabs, import it into Zen as bookmarks, then pin the ones you want.
